# 用户使用文档

## 组件用途

该组件用于训练 MindYOLO 模型，支持 `yolov5` 与 `yolov10`，目标环境为华为昇腾 910C，亦兼容本地 mac/Linux CPU 调试。

## 关键参数

- `--mindyolo_root`  
  MindYOLO 工程目录，默认优先使用内嵌的 `./mindyolo_core`，缺失时回退 `../mindyolo-master`。
- `--model_type`  
  模型类型，可选 `yolov5` 或 `yolov10`。
- `--model_scale`  
  模型规模，如 `n/s/m/l/x`（`yolov10` 额外支持 `b`）。
- `--config`  
  显式指定 yaml 配置路径，优先级高于 `model_type + model_scale` 自动映射。
- `--epochs` / `--per_batch_size` / `--img_size`  
  训练轮数、单卡 batch、输入尺寸。
- `--device_target`  
  设备类型，默认 `Ascend`，本地调试可填 `CPU`。
- `--is_parallel`  
  是否开启分布式训练。
- `--weight`  
  初始权重路径（MindYOLO `.ckpt`，可选）。
- `--save_dir`  
  训练输出目录。
- `--extra_args`  
  透传给 `mindyolo_core/train.py` 的额外参数（如 `--strict_load False`、`--ms_loss_scaler none`）。

## 启动事项（Ascend 910C）

### 一、代码层（已适配，无需改）

所有 mac / CPU 专用补丁都有 `if device_target=="CPU"` 或 `if Darwin` 分支保护，**910C 路径不受影响**：

| 改动 | 触发条件 | 在 910C 上 |
|---|---|---|
| `train.py` 自动注入 `--ms_mode 1 --ms_jit False --ms_amp_level O0` | `--device-target=CPU` | 不启用 |
| `train.py` 注入 `OBJC_DISABLE_INITIALIZE_FORK_SAFETY=YES` | `platform.system()=="Darwin"` | 不启用 |
| `train_step_factory.py` 用占位 `all_finite` | `device_target=="CPU"` | 不启用，走原 `mindspore.amp.all_finite` |
| `dataset.py` 的 `imgIds` int 转换 fallback | 全平台 | 启用，仅影响非数字文件名的 COCO eval，无副作用 |
| `yolov5_loss.py` 用 `ops.amax` 代替 `.max(dim)` | 全平台 | 启用，行为更鲁棒，数值结果不变 |

补丁详见 `维护说明.md` 的"对内嵌 core 的本地补丁"。

### 二、配置层（必须改 / 建议改）

1. **数据路径**：`data/<your_dataset>.yaml` 内 `train_set/val_set/test_set` 当前为 mac 绝对路径，910C 上必须改为部署节点上能访问到的绝对路径或基于 cwd 的相对路径。
2. **`data.num_parallel_workers`**：本地调试用 `1`，910C 上建议 `4` 或 `8`。
3. **`requirements.txt` 里的 `mindspore`**：默认装 PyPI 通用包（CPU 版）。910C 必须装与 CANN 配套的 Ascend 版 MindSpore，建议在 Ascend 镜像里把 `mindspore` 一行注释掉，由基础镜像或 CANN 安装脚本提供。
4. **`Dockerfile`**：当前为通用 Python 基础镜像，910C 部署应换成 Ascend 官方 `mindspore-ascend:xxx` 或带 CANN 的镜像。

### 三、910C 启动命令（示例）

单卡：

```bash
python mindyolo-train-master/train.py \
  --model-type yolov5 \
  --config /path/to/yolov5n_number.yaml \
  --device-target Ascend \
  --is-parallel False \
  --epochs 300 \
  --per-batch-size 32 \
  --img-size 640 \
  --weight ./mindyolo-train-master/weights/yolov5n_xxx.ckpt \
  --save-dir ./mindyolo-train-master/runs \
  --extra-args --strict_load False
```

多卡（用 `msrun` 或 `mpirun` 启动）：

```bash
msrun --worker_num=8 --local_worker_num=8 --master_port=8118 \
  mindyolo-train-master/train.py \
  --model-type yolov5 \
  --config /path/to/yolov5n_number.yaml \
  --device-target Ascend \
  --is-parallel True \
  --epochs 300 \
  --per-batch-size 32 \
  --img-size 640 \
  --save-dir ./mindyolo-train-master/runs
```

### 四、本地 mac/Linux CPU 调试启动命令（示例）

```bash
python mindyolo-train-master/train.py \
  --model-type yolov5 \
  --config /abs/path/to/yolov5n_number.yaml \
  --device-target CPU \
  --is-parallel False \
  --epochs 1 \
  --per-batch-size 1 \
  --img-size 320 \
  --weight ./mindyolo-train-master/weights/yolov5n_xxx.ckpt \
  --save-dir ./mindyolo-train-master/runs_local \
  --extra-args --strict_load False
```

CPU 模式下 wrapper 会自动追加 `--ms_mode 1 --ms_jit False --ms_amp_level O0`，无需手动指定。

### 五、上 910C 之前建议跑一遍的清单

- [ ] 数据集 `train/val/test.txt` 内的图片路径在 910C 节点上能访问
- [ ] `data.num_parallel_workers` 调回 `4~8`
- [ ] MindSpore 版本与 CANN 版本严格对应（参考 MindSpore 官方版本矩阵）
- [ ] 单卡先 `--is-parallel False` 通一遍，再切 `True` + `msrun/mpirun` 多卡
- [ ] 确认安装了 `setuptools<81`（已写进 `requirements.txt`）
- [ ] 自定义类别数（`nc`）与预训练 ckpt 的 head 形状不一致时，加 `--extra-args --strict_load False`
