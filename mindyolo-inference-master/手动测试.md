# MindYOLO Inference 手动测试说明

本文面向在本仓库内**命令行自测**三种入口：`workflow_main.py`（本地路径）、`batch_main.py`（MinIO 批处理）、`http_main.py`（HTTP 服务）。参数以各脚本中 `argparse` 为准。

## 1. 环境与 MindYOLO 源码

1. 进入目录：`mindyolo-inference-master`。
2. 安装依赖：`pip install -r requirements.txt`。
3. **MindSpore**：按本机目标设备安装（CPU / GPU / Ascend）；仅 CPU wheel 时必须显式 **`--device-target CPU`**，否则默认 `Ascend` 会报错。
4. **MindYOLO 源码**：已内嵌在 **`service/mindyolo/`**（子进程执行其中的 `demo/predict.py` 或 `deploy/mslite_predict.py`）。**默认不必传 `--mindyolo-root`**；若要用外部副本再显式传入。

## 2. 三种入口对比

| 入口 | 模型来源 | 数据来源 | 结果 |
|------|----------|----------|------|
| `workflow_main.py` | 本地 `--model-path` | 本地 `--data-path`（图/目录/视频等） | 本地 `--output-dir`；可选 MinIO 上传 |
| `batch_main.py` | MinIO `--model-minio-path` | MinIO `--data-minio-path` | 本地 `./result` 后上传 `--result-minio-path` |
| `http_main.py` | MinIO `--model-minio-path`（启动时下载） | HTTP 表单 **`upload_files`** | 接口 `FileResponse` 返回文件 |

## 3. MinIO 路径约定

`myutils/myminio.py` 中路径格式为 **`桶名/对象键或前缀`**（第一段为 bucket）。

- **单文件**：`face-detect-images/mindyolo_weights/yolov5s.ckpt`（**不要**以 `/` 结尾）。
- **前缀目录（批量列举）**：`face-detect-images/batch-input/`（**必须以 `/` 结尾**）。

## 4. `workflow_main.py`（推荐先测）

### 4.1 仅本地（不上传 MinIO）

```bash
cd mindyolo-inference-master

python3 workflow_main.py \
  --model-path "$(pwd)/weights/yolov5s_300e_mAP376-860bcf3b.ckpt" \
  --data-path "$(pwd)/戴头盔.jpg" \
  --log-path "$(pwd)/run_manual_infer.log" \
  --device-target CPU \
  --backend ckpt \
  --model-type yolov5 \
  --model-scale s \
  --output-dir "$(pwd)/runs_infer_local"
```

- **`--data-path`**：可为单图、图片目录、视频文件、摄像头编号、RTSP/RTMP/HTTP 流等（由 `service/inference.py` 兼容层处理）。
- **`--output-dir`**：推理写出目录；未传 MinIO 时结果只在此目录。

### 4.2 推理后上传 MinIO（命令行）

需同时提供 **`--result-minio-path`** 与 **`--endpoint` / `--access-key` / `--secret-key`**；**`--secure`** 可为 `true`/`false`/`1`/`0`。

```bash
python3 workflow_main.py \
  --model-path "$(pwd)/weights/yolov5s_300e_mAP376-860bcf3b.ckpt" \
  --data-path "$(pwd)/戴头盔.jpg" \
  --log-path "$(pwd)/run_manual_infer.log" \
  --device-target CPU \
  --output-dir "$(pwd)/runs_infer_local" \
  --result-minio-path "face-detect-images/infer-results/manual-001/" \
  --endpoint "10.10.102.63:30090" \
  --access-key "admin" \
  --secret-key "Ab123456" \
  --secure "false"
```

### 4.3 推理后上传 MinIO（环境变量）

命令行未写 MinIO 时，可由 **`MINIO_ENDPOINT` / `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY` / `MINIO_SECURE`** 补全；结果路径可用 **`MINIO_RESULT_MINIO_PATH`**，或由 **`MINIO_BUCKET`** + 可选 **`MINIO_RESULT_PREFIX`**（默认 `infer-results`）拼接。

```bash
export MINIO_ENDPOINT=10.10.102.63:30090
export MINIO_ACCESS_KEY=admin
export MINIO_SECRET_KEY=Ab123456
export MINIO_SECURE=false
export MINIO_BUCKET=face-detect-images
# 可选：export MINIO_RESULT_PREFIX=infer-results

python3 workflow_main.py \
  --model-path "$(pwd)/weights/yolov5s_300e_mAP376-860bcf3b.ckpt" \
  --data-path "$(pwd)/戴头盔.jpg" \
  --log-path "$(pwd)/run_manual_infer.log" \
  --device-target CPU \
  --output-dir "$(pwd)/runs_infer_local"
```

### 4.4 自定义网络 yaml

默认按 **`--model-type`** + **`--model-scale`** 映射到内嵌 `service/mindyolo/configs/...`。若要用自己的 yaml：

```bash
python3 workflow_main.py \
  --model-path "/绝对路径/best.ckpt" \
  --data-path "/绝对路径/1.jpg" \
  --log-path "$(pwd)/run.log" \
  --config "/绝对路径/yolov5n.yaml" \
  --device-target CPU \
  --output-dir "$(pwd)/runs_custom"
```

## 5. `http_main.py` + `curl`

### 5.1 启动服务

启动时从 MinIO 下载模型到本地 **`./models`**，监听 **`0.0.0.0:8000`**（代码写死端口）。日志优先 **`/var/log/logout.log`**；若无写权限则自动落到 **`./runs_batch/logout.log`**（与 `batch_main` 相同逻辑）。

```bash
cd mindyolo-inference-master

python3 http_main.py \
  --model-minio-path "face-detect-images/mindyolo_weights/yolov5s_300e_mAP376-860bcf3b.ckpt" \
  --endpoint "10.10.102.63:30090" \
  --access-key "admin" \
  --secret-key "Ab123456" \
  --secure "false" \
  --device-target CPU \
  --backend ckpt \
  --model-type yolov5 \
  --model-scale s
  
```

### 5.2 健康检查与推理

```bash
curl -sS "http://127.0.0.1:8000/api/v1/ready"
```

```bash
cd mindyolo-inference-master

curl -sS -X POST "http://127.0.0.1:8000/api/v1/inference" \
  -F "upload_files=@戴头盔.jpg" \
  -o "./http_infer_out.jpg"
```

返回体为文件流，保存名可按实际类型改为 `.jpg` 等。

## 6. `batch_main.py`

数据与模型均从 MinIO 拉取；需先把待测图（或目录前缀）放到 MinIO。

日志：未传 **`--log-path`** 时，若本机对 **`/var/log`** 无写权限（如 macOS 普通用户），会自动写到 **`./runs_batch/logout.log`**；也可显式 **`--log-path "$(pwd)/batch.log"`**。

```bash
cd mindyolo-inference-master

python3 batch_main.py \
  --model-minio-path "face-detect-images/mindyolo_weights/yolov5s_300e_mAP376-860bcf3b.ckpt" \
  --data-minio-path "face-detect-images/batch-input/戴头盔.jpg" \
  --result-minio-path "face-detect-images/infer-results/batch-001" \
  --endpoint "10.10.102.63:30090" \
  --access-key "admin" \
  --secret-key "Ab123456" \
  --secure "false" \
  --device-target CPU \
  --backend ckpt \
  --model-type yolov5 \
  --model-scale s

python3 batch_main.py \
  --model-minio-path "face-detect-images/mindyolo_weights/yolov5s_300e_mAP376-860bcf3b.ckpt" \
  --data-minio-path "face-detect-images/batch-input/test_face.mp4" \
  --result-minio-path "face-detect-images/infer-results/batch-001" \
  --endpoint "10.10.102.63:30090" \
  --access-key "admin" \
  --secret-key "Ab123456" \
  --secure "false" \
  --device-target CPU \
  --backend ckpt \
  --model-type yolov5 \
  --model-scale s
```

- **`--data-minio-path`** 与桶内对象键一致；多图同一前缀时用 **`桶/前缀/`**（末尾 `/`）。

## 7. 按平台 JSON 拼命令（自检）

仓库内 **`scripts/run_platform_inference_json.py`** 读取 `mindyolo_inference_config.json` / `yolov5_inference_config.json` 的 `run` + `input` / `log` / `config` 拼出启动命令；**须在 JSON 的 `input[].path`、`log.path` 等填入本机有效路径**。

```bash
cd mindyolo-inference-master

python3 scripts/run_platform_inference_json.py --json mindyolo_inference_config.json --dry-run
```

## 8. 常用参数说明（速查）

| 参数 | 默认 | 说明 |
|------|------|------|
| `--device-target` | `Ascend` | `CPU` / `GPU` / `Ascend` 等与 MindSpore 一致 |
| `--backend` | `ckpt` | `ckpt` 走 `demo/predict.py`；`mindir` 走 `deploy/mslite_predict.py` |
| `--model-type` | `yolov5` | `yolov5` / `yolov10` |
| `--model-scale` | `s` | 与内嵌 `configs` 映射一致；YOLOv10 含 `b` 等 |
| `--mindyolo-root` | 内嵌 `service/mindyolo` | 一般省略 |
| `--log-path` | （仅 `batch_main`） | 省略时按上文自动选可写路径 |
| `--config` | 空 | 非空则作为 MindYOLO `--config` 的 yaml 绝对路径 |

## 9. 与训练工程衔接

离线权重路径指向 **`mindyolo-train-master`** 训练产出目录下的 `*.ckpt` 即可；**`--model-type` / `--model-scale` / `--config`** 需与训练时的网络 yaml 一致（或传同一 yaml 的绝对路径）。
