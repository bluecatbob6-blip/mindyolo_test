# mindyolo-inference-master 维护说明

## 当前目标
- 按 `yolov5-inference-master` 的完整工程结构保留项目形态。
- 推理链路使用 **`service/mindyolo/`** 内嵌的上游 MindYOLO 源码（与 `yolov5-inference` 内嵌 `service/yolov5` 同思路），默认 **`--mindyolo-root`** 即该目录；仍可通过参数指向外部副本。支持：
  - `--model_type`：`yolov5`/`yolov10`
  - `--backend`：`ckpt`/`mindir`

## 与 YOLOv5 推理组件的平台对齐

- 根目录对照说明见 `../yolov5-inference-master/推理组件接口与实现说明.md`。
- `mindyolo_inference_config.json` / `yolov5_inference_config.json`：已与 `yolov5_inference_config.json` 同级字段对齐（`input` 使用 `--model-path` + `--data-path`，补充 `log`、`minio_authorization`、`config` 中的 `--result-minio-path`；MindYOLO 专有项仍在 `config` 中）。
- `workflow_main.py`：本地 `--model-path` + `--data-path`（图片/目录/视频/流）；可选 `--log-path`。若同时传入 `--result-minio-path` 与 `--endpoint` / `--access-key` / `--secret-key`（`--secure` 可选，默认 false），推理结束后将 **`--output-dir` 整个目录** 上传到 MinIO 指定前缀。
- `service/inference.py`：已增加 YOLOv5 source 兼容层。`--data-path` 可按原 YOLOv5 语义接收单图、图片目录、视频文件、URL 图片/视频、摄像头编号、RTSP/RTMP/HTTP 流；MindYOLO 内核仍按单图推理，兼容层负责批量循环、逐帧推理和 mp4 结果合成。
- `http_main.py` / `batch_main.py`：`--model-type` 默认 `yolov5`，`--backend` 默认 `ckpt`，外部平台仅按 YOLOv5 固定参数调用时也可启动。
- `yolov5_inference_config.json` / `inference.json`：已收紧为与原 `yolov5-inference-master` 同形字段；MindYOLO 扩展参数保留在 `mindyolo_inference_config.json`。
- `myutils/myminio.py`：修复目录上传时 `os.path(ff_path)` 的模板遗留错误，确保 batch 结果目录能上传 MinIO。

## 已完成改动
- 已补齐模板目录结构（来源：`yolov5-inference-master`）。
- 新增并启用通用推理入口：`workflow_main.py`。
  - 支持 `--model-type/--model_type`、`--backend`、`--model-path`、`--image-path` 等参数。
- 新增推理服务层：
  - `service/inference.py`
  - `service/__init__.py`
- 推理适配逻辑：
  - `backend=ckpt` -> 调 `service/mindyolo/demo/predict.py`
  - `backend=mindir` -> 调 `service/mindyolo/deploy/mslite_predict.py`
  - 自动解析模型 yaml（支持按 `model_type + model_scale` 默认映射，或 `--config` 显式覆盖）。
- `batch_main.py` 已适配为 MindYOLO 批量推理并回传 minio。
- `http_main.py` 已增加 MindYOLO 关键参数透传。
- `http_api/router/inference.py` 调用 **`inference(model_path, options).run(source)`**（`service/inference.py`）。
- `config/config.py` 已补充 MindYOLO 运行所需全局字段。
- `inference.json`、`yolov5_inference_config.json` 已改为 MindYOLO 通用描述。

## 关键入口与职责
- 命令行自测步骤与示例见 **`手动测试.md`**。
- `workflow_main.py`：离线单次推理入口（推荐）。
- `batch_main.py`：minio 批量推理入口。
- `http_main.py`：HTTP 服务入口（FastAPI）。
- `service/inference.py`：统一后端分流与命令构建。
